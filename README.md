# 每日復盤與時間手帳 (Daily Review & Planner)

專為個人日常覆盤、精準時間記錄與明日待辦規劃設計的跨裝置（手機 / 電腦）網頁應用。支援離線執行、歷史翻閱檢索、手機 PWA 桌面 App，以及**多設備跨端無縫自動同步（解決版本衝突）**。

---

## ☁️ 跨設備（手機 ⇄ 電腦）雲端同步設定指南

為徹底避免「手機更新、電腦又更新，導致版本混亂或覆蓋」的問題，本工具內建**「毫秒級時間戳 Smart Merge 智慧合併機制」**：
- **不同天分別記錄**：自動雙向合併補齊，絕不互相抹除。
- **同一天修改**：嚴格以「最新修改的時間戳為準」，並在畫面上方即時提示，確保兩端永遠是最新版。

### 🚀 3 步驟啟用跨設備同步（完全免費、私有安全）：

#### 第一步：取得 GitHub Personal Access Token (PAT)
1. 登入您的 GitHub 帳號，前往 Token 建立頁面：
   👉 [前往 GitHub 快速建立 Token](https://github.com/settings/tokens/new?description=DailyReviewSync&scopes=gist)
2. 頁面上的 Note 輸入 `DailyReviewSync`，**Select scopes** 勾選 **`gist`** 即可。
3. 滾動到最下方點擊綠色按鈕 **Generate token**。
4. 複製生成的 Token（格式如 `ghp_xxxxxxxxxxxxxxxxxxxx`，注意離開頁面後無法再次查看）。

#### 第二步：在第一台設備（例如電腦）綁定
1. 在網頁頂部點擊 **「雲端同步」** 按鈕（或管理選單中的「跨設備雲端設定」）。
2. 在 **GitHub Personal Access Token** 欄位貼上剛剛複製的 Token。
3. **同步資料庫 ID (Gist ID)** 欄位請**保持留空**（系統會在雲端自動為您建立專屬的私有資料庫）。
4. 點擊 **「儲存並立即同步」**。
5. 同步完成後，視窗內會自動產生專屬的 **Gist ID**（一串英數代碼）。

#### 第三步：在第二台設備（例如手機）連線
1. 在手機瀏覽器打開相同的網頁。
2. 點擊底部導航欄的 **「同步」**（或點擊「管理」➔「跨設備雲端同步設定」）。
3. 貼上**相同的 GitHub Token** 與第一台設備產生的 **Gist ID**。
4. 點擊 **「儲存並立即同步」**。

🎉 **大功告成！** 從此無論在電腦記錄或手機打卡：
- 開啟或解鎖手機時：**自動拉取雲端最新修改**。
- 編輯或打勾時：**1.5 秒自動背景靜默推送到雲端**。
- 兩台設備資料隨時保持最新，再也不怕版本衝突！

## 🌟 核心特色功能

### 1. 📱 手機與電腦雙平台深度適配
- **電腦端**：寬螢幕多欄排版，一目了然記錄生活飲食、專案進度與明日規劃。
- **手機端**：底部懸浮快捷導航欄（📝 記錄、📚 翻閱、☁️ 同步、📋 復盤、💾 管理），支援大按鍵觸控操作與防誤觸設計。
- **📲 PWA 手機獨立 App 支援**：
  - **iPhone (iOS Safari)**：開啟網頁 ➔ 點擊底部「分享」按鈕 ➔ 選擇「**加入主畫面**」。
  - **Android (Chrome)**：開啟網頁 ➔ 點擊右上角選單 ➔ 選擇「**安裝應用程式**」或「**新增至主畫面**」。
  - 安裝後無需瀏覽器網址列，可如原生 App 般全螢幕極速開啟，無網路亦可離線記錄！

---

### 2. 📚 完整歷史復盤翻閱與全文檢索庫
- **時間軸卡片流**：依照日期由新到舊展示過往每一天的完整復盤卡片。
- **即時全文關鍵字檢索**：
  - 輸入關鍵字（例如：「格雷」、「Duolingo」、「牛肉湯麵」、「番茄小說」）。
  - 系統瞬間篩選出包含該詞彙的所有歷史日期，並以黃底亮色標記關鍵字！
- **時間區間篩選**：支援「全部歷史」、「近 7 天」、「近 30 天」、「本月」快速切換。
- **快捷回顧與編輯**：
  - 每一天卡片皆提供 **「📋 複製文本」**（提取該日復盤文字）。
  - 提供 **「✏️ 載入編輯」**（一鍵跳轉到該天補記或修改）。
  - 提供 **「📑 匯出選取期間報告」**（將一週或整月復盤統整成一份大報告）。

---

### 3. 🎯 五大專屬分類與自由預留格子
- **生活**：
  - **家務**：提供「洗衣服、曬衣服、洗碗、整理回收、掃拖」一鍵快捷標籤，亦可新增自訂家務。
  - **飲食**：早餐、午餐、晚餐、點心/飲品格子，記下用餐內容與當下時間。
- **工作**：預留「專案/標題」格子（例如：格雷農科專、格雷SBIR）＋「工作內容細項」，追蹤專案產出。
- **娛樂**：預留「類別」格子（例如：番茄小說、追劇、遊戲、閱讀）＋「內容與心得」。
- **學習**：預留「項目」格子（例如：英文、程式開發、技能學習）＋「內容細節」。
- **其他事件**：隨手記下外出雜項與臨時備忘。

---

### 4. ⏱️ 全面採用「24小時制」自訂時間與「一鍵現在時間」
- **純粹 24 小時制 (HH:mm)**：全站時間欄位全數統一為 24 小時制（例如 `08:00`、`13:30`、`21:45`），已徹底取消上午/下午按鈕與切換干擾。
- **預設自動帶入現在時間**：新增欄位與打卡預設抓取當下時間（24 小時制時:分）。
- **完全自由自訂**：
  - **新增輸入列**：各類別（生活家務、飲食、工作、娛樂、學習、其他、明日待辦）均配備 24 小時制時間選取器 `<input type="time">`，想補記過去時間或預排時間皆可自訂。
  - **已記錄事項**：清單中每筆項目時間皆為可點擊的時間輸入框，直接點擊即可修改。
  - **一鍵填入現在時間**：每處時間欄位旁均設有「時鐘 🕒」快捷按鈕，點擊立即更新為當前系統最新 24 小時制時間。
- **完成度打卡與進度條**：Checkbox 打卡後文字自動加上刪除線，頂部實時統計**今日總完成進度條**。

---

### 5. 📌 明日待辦流轉
- 專屬「明日待辦」整理區。
- **「一鍵將今日未完成帶入明日待辦」**：晚上復盤時自動抓出未完成工作與學習事項，工作無縫銜接。
- **「將昨日預排待辦匯入今日工作」**：隔天早晨開啟時，一鍵將昨日規劃好的待辦直接轉入今日任務清單。

---

## 💾 本地備份與救急選項

- 即便未連網或未綁定雲端，資料依然完好保存在本地 `localStorage`。
- 支援「匯出完整備份 (JSON)」與「匯入備份資料」。
- 雲端同步設定內提供「從雲端強制拉取」與「本地強制推送到雲端」，提供多重安全保障。
