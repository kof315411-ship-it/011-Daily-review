# 每日復盤與時間手帳工具 (Daily Review & Planner)

一個專為個人日常覆盤、精準時間記錄與明日待辦規劃設計的純前端免安裝網頁工具。

---

## 🌟 核心特色功能

1. **依據使用習慣分類**：
   - **生活**：
     - **家務**：提供「洗衣服、曬衣服、洗碗、整理回收、掃拖」等一鍵快捷標籤，亦可隨意自訂新家務。
     - **飲食**：固定區分早餐、午餐、晚餐、點心/加餐，記錄用餐內容與時間。
   - **工作**：預留「專案/標題」格子（例如：格雷農科專、格雷SBIR、格雷創業綻放）＋「具體內容」，精準追蹤進度。
   - **娛樂**：預留「類別」格子（例如：番茄小說、追劇、遊戲、閱讀）＋「內容與備註」。
   - **學習**：預留「項目」格子（例如：英文、程式開發、技能學習）＋「內容細節」。
   - **其他事件**：彈性填寫雜項、外出或隨手筆記。

2. **時間戳與完成度打卡**：
   - 每項記錄時**自動抓取當下時間**（精確到時:分），亦可點擊時間圖示隨時更新為當下時間或手動調整。
   - 具備 Checkbox 完成狀態勾選，打勾後帶有刪除線樣式。
   - 頂部實時計算**今日總完成率進度條**（例如：`8 / 10 項目 (80%)`）。

3. **明日待辦事項整合**：
   - 專屬「明日待辦」整理區。
   - 提供**「一鍵將今日未完成事項轉移至明日待辦」**，工作/學習不漏接。
   - 隔日可**「一鍵將昨日預排待辦匯入今日工作」**，無縫銜接每一天。

4. **一鍵生成與複製復盤文字（還原標準版型）**：
   - 點擊「生成復盤文本」，自動整理為格式化文字：
     ```text
     0909 (三)
     生活
       · 家務：洗衣服、曬衣服、洗碗、整理回收
       · 飲食：
       - 早餐：鷹嘴豆起司雞饅頭、米牛奶
       - 午餐：牛肉湯麵、小菜乾絲、泡菜
       - 晚餐：炸春捲河粉、奇異果鳳梨汁
     工作
       · 格雷農科專：完成結案報告修改
       · 格雷SBIR：確認會計查核時間、回信、承辦聯繫
       · 格雷創業綻放：約會議時間
     娛樂
       · 番茄小說：穿成侯夫人，讓當外室的女主絕望（有空就看一些）
     學習
       · 英文：Duolingo、刷刷庫、26秒背單字、Speak
     其他事件
       · 
     ```
   - 支援「一鍵複製全文」，便於貼至 LINE、Notion、筆記軟體或社群。

5. **本地儲存與安全備份**：
   - 自動保存至瀏覽器 `localStorage`，關閉或重新整理不遺失資料。
   - 支援完整備份「匯出 JSON」與「匯入 JSON」，跨電腦換設備也能輕鬆遷移。

---

## 🚀 如何使用

1. **直接開啟**：
   - 在檔案總管中雙擊 `index.html`，即可在任何瀏覽器（Chrome, Edge, Safari, Firefox 等）中直接開啟使用。
2. **日常操作流程**：
   - 早上/中午/晚上：記錄生活三餐與家務，點擊工作/學習新增任務。
   - 下班/睡前復盤：檢視今日清單，勾選完成項目。
   - 點擊「一鍵將今日未完成轉入明日待辦」，規劃隔天代辦。
   - 點擊「生成復盤文本」並一鍵複製，完成每日復盤打卡！
