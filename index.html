跨設備雲端同步設定

電腦 ⇄ 手機 雙向無縫同步，永不遺失

如何實現手機與電腦自動同步？

透過您的 GitHub Gist 私有空間 作為跨端中央資料庫。每次手機或電腦記錄時，系統會比對毫秒級時間戳（以最新編輯的一端為準），自動雙向合併，徹底避免版本混亂。

前往一鍵生成 Token

Token 僅需勾選 gist 權限即可。資料 100% 儲存在您自己的私有 GitHub，隱私安全無虞。

若要在第二台設備（如手機）綁定，只需把電腦端生成的 Gist ID 複製到手機貼上即可。
